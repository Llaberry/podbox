## The findings worth carrying forward

1. ⛔ **The completion layer runs on the HOST, and two fixups need a COMMAND
   inside the rootfs.** libzypp hands libcurl a `CAPATH`, a hash-indexed
   directory, so every CAfile podbox wrote was a file it never opened. ⚠ The
   discriminator was one command: `curl --cacert` returns 200 where `curl`
   alone returns error 60.
2. ⛔ **A guard with two answers could not say "I could not look".**
   `matches!(kind, Kind::Dir)` folded *not a directory* into *left the root*, so
   a CApath behind a symlink out of the rootfs read as absent and the layer went
   on quietly. `Root::reach` has three answers, and `Unreachable` prints.
3. ⛔ **A shipped `libc.so.6` has 0 defined symbols in `.symtab` and 3136 in
   `.dynsym`.** A reader that consults `.symtab` refuses everything. Three more
   traps sat beside it: the version is checked BEFORE the name because that is
   the loader's order, `VER_FLG_BASE` marks the SONAME rather than a version,
   and gcc's weak `_ITM_*` imports are not requirements.
4. ⛔ **`statx(2)` is what modern coreutils `stat` calls.** Until it was
   interposed, glibc read back `0:0` and musl read `0:42` from the same object
   and the same memo, because only one libc took the `stat` path.
5. ⛔ **The launcher kept the caller's stdio.** `id="$(podbox run -d …)"` leaves
   the shell reading a pipe the container now owns, so under load the read
   returned before the launcher had recorded anything. Neither of the two causes
   T-0608 wrote down was it, which is why the entry refused to act on them.
6. ⛔ **One verb was served by another verb's parser and nothing said so.**
   `podbox create --no-steps` was accepted and acted on while the table listed
   the flag under `run` and `exec` only, and `podbox create --no-such-flag`
   answered `podbox run: unknown option`. Found by the door sweep, not by a
   failure.
7. ⛔ **`--strict`'s fourth reason had never been seen to refuse.** It counts
   T-0412's steps, and the clause that drives `--strict` used an image with
   none. Found by the guard-mutation lens.
8. ⛔ **An exit code read from the wrong process.** `./script > log 2>&1;
   echo "rc=$?"` in a background wrapper reports the ECHO's code, so a target
   image build that exited 2 was read as 0 and two experiments went on
   reporting SKIP for another twenty minutes.
